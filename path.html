Learning path

One path through everything. Each unit is a course and each circle is a lesson: a lecture, a problem set or a quiz. Work from the top; the highlighted circle is your next step, and every lesson ends with a button that takes you to the next one, across course boundaries. Progress is stored only in this browser.

Already know a unit? Use “I know this” on it to mark its lessons done. The curriculum page lists the same courses as a catalogue, and the prerequisite map shows how they depend on each other.

MiBeM

A free university curriculum in computational materials science, from first-year foundations to graduate methods.
