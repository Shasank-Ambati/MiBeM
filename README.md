# MiBeM

A static knowledge repository for learning computational materials science. Each topic is a self-contained page covering the concepts, equations, trade-offs and practical advice for one method or idea, with animated figures and references.

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Layout

- `index.html`: landing page and topic list
- `computational/`: one HTML page per topic
- `assets/style.css`: shared stylesheet
- `assets/animations/`: animated GIF and SVG figures used by the pages
