MiBeM

A growing, static repository for learning metallurgy and computational materials science, with steel and process metallurgy as the running theme.

About this site

MiBeM began as notes on mineral beneficiation and metallurgy. It is now also a working study guide for computational materials science, written for a practising metallurgist who wants to apply simulation and data methods to real R&D problems.

One new page is added each day. Every page is written in original words, states what you should be able to do afterwards, and lists references for further reading.
